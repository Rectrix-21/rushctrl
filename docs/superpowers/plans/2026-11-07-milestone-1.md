# Milestone 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Save and enforce the manager-to-employee staffing workflow, with beginner explanations and reproducible acceptance checks.

**Architecture:** Extend the existing API with Identity, server-derived organization scope and focused scheduling services. Keep Next.js as the same-origin UI and PostgreSQL as the source of truth. Implement inline in the open workspace on `milestone-1`, following the existing execution preference.

**Tech Stack:** Existing .NET 10, EF Core/Npgsql, PostgreSQL 18, Next.js, React and TypeScript; matching Identity EF package and schema validation for forms.

**Spec:** `docs/superpowers/specs/2026-11-07-milestone-1-design.md`, elaborating the approved `2026-11-03-milestone-0-design.md`.

## Global Constraints

- No deployment, paid service, external account, real employee data or production-readiness claim.
- Cookies are HttpOnly, SameSite and secure outside local Development.
- All intervals are half-open `[start, end)`.
- No AI branding, boilerplate authorship comments or artificial co-author trailers.
- After each increment report what changed, why, which files matter, observed test results, and a small exercise the owner can try.

## Review Focus

- Stale sessions and CSRF tokens must fail safely, including when switching users.
- Another organization's UUIDs must never expose records or attach its resources to a write.
- Adjacent, overnight and daylight-saving intervals must retain location-time semantics.
- Concurrent assignments must preserve overlap and configured weekly-hour rules.
- Partial staffing coverage, duplicate requests and stale browser data must produce truthful results.
