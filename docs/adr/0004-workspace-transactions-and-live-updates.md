# ADR 0004: workspace transactions, isolated experiments and live invalidation

Status: accepted for Milestone 2. API, web/browser and Compose passed in [Checks run 42499631753](https://github.com/Rectrix-21/rushctrl/actions/runs/42499631753) on `dd44c39`.

One endpoint filter owns the organization write transaction. It locks the organization, validates a lab's captured generation when applicable, runs the scheduling operation, numbers and stores minimal audit entries, saves, and commits. Only then does it publish an invalidation. This serializes writes within one organization, simplifying audit order and reset-versus-approval behavior for the local demo. It trades write concurrency for an explicit boundary; no throughput claim is made. Employee locks and the global overlap constraint remain necessary across organizations.

A Friday Rush lab is a separate organization owned by one manager of the reserved synthetic source. Its eight generated identities have no passwords and never reuse ordinary employee IDs. Creation requires Development and an explicit opt-in. Apply uses a pristine future fixture; it raises demand, opens an absent employee's shift, removes their fixture availability and creates an explicit SimulationCallout. It runs the real approval and assignment services. Reset clears only lab staffing records, reuses identities/locations/skills, preserves audit and rotates generation. A stale form cannot write into the new experiment. Normal organizations have no reset endpoint.

SignalR announces only organization/generation. A screen retrieves the authoritative HTTP state; reconnect rejoins a server-validated group and reloads even if messages were missed. Long Polling is deliberate for the existing Next.js same-origin rewrite: a bounded 15-second poll avoids relying on WebSocket upgrade support. One UI connection belongs to the current displayed identity and organization. Account checks before join/rejoin/save never silently adopt a changed shared cookie. Editing queues ordinary invalidations; reset invalidation closes old forms and reloads metadata.

Delivery is best-effort. There is no outbox, broker, cross-instance backplane or guaranteed event stream. Notification failure after commit must leave the save successful; manual Refresh and reconnect reload cover ordinary recovery. An offline live connection is shown separately from API/database readiness. These choices suit a synthetic local application, not a production deployment claim.
